Yozmang — gapiring

Ctrl + Caps Lock ni bosib turib gapiring. Qo‘yib yuborganingizda aytganingiz kursor turgan joyga matn bo‘lib yoziladi — Telegram, Word, brauzer, xohlagan dasturda.

Windows uchun yuklab olish

Windows 10 / 11, 64-bit · bepul va ochiq kodli · macOS versiyasi keyinroq

O‘rnatgandan keyin

  1. Aisha API kalitini oling Nutqni matnga o‘girish aisha.group orqali ishlaydi — o‘zbek tiliga o‘rgatilgan yagona xizmat. Ro‘yxatdan o‘tib kalitni olasiz. To‘lov ishlatganingizcha: daqiqasi ~425 so‘m, oylik to‘lov yo‘q.
  2. Kalitni dasturga qo‘yib qo‘ying Dastur birinchi ochilganda o‘zi so‘raydi. “Tekshirish” tugmasi kalit ishlashini darhol aytadi. Kalit shu kompyuterda shifrlangan holda saqlanadi va boshqa hech qayerga yuborilmaydi.
  3. Gapirib ko‘ring Ekran pastida kichkina belgi paydo bo‘ladi — dastur ishlayotgani shundan bilinadi. Ctrl + Caps Lock ni bosib turib gapirsangiz, belgi kengayib ovozingizni ko‘rsatadi. Bekor qilish uchun Esc.

“Windows protected your PC” chiqsa

Bu normal holat — dastur hali imzolanmagan. Sertifikat pullik bo‘lgani uchun hozircha yo‘q, shuning uchun Windows notanish dasturdan ogohlantiradi. Ochish uchun:
  1. More info ni bosing
  2. Run anyway ni bosing
Antivirus ham shikoyat qilishi mumkin: dastur klaviaturani tinglaydi va tugma bosishini yuboradi — keylogger bilan bir xil ko‘rinadi. Kodning hammasi ochiq, GitHub’da o‘qib ko‘rsangiz bo‘ladi.

Ovozim qayerga ketadi?
Faqat Aisha’ga, matnga o‘girish uchun. Ovoz hech qayerda saqlanmaydi. Aytgan matnlaringiz esa kompyuteringizda tarixda qoladi — istagan payt o‘chirasiz yoki butunlay yozib qo‘yishni o‘chirib tashlaysiz.
Ruscha va inglizcha ham bo‘ladimi?
Ha, Sozlamalardan tilni almashtirasiz.
Internet kerakmi?
Ha. Matnga o‘girish serverda bo‘ladi, shuning uchun internetsiz ishlamaydi.
Aytilgan matnlarni qayerdan ko‘raman?
Trey belgisini bosing — dastur oynasi ochiladi, hamma aytganlaringiz ro‘yxat bo‘lib turadi. Bir bosishda nusxa olasiz.
Yangilanish o‘zi keladimi?
Ha, dastur yangi versiyani o‘zi topib yuklaydi va keyingi ochilishda o‘rnatadi.
